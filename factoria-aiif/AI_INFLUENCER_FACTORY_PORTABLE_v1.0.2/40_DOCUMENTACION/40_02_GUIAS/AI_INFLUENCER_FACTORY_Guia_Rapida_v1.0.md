# AI INFLUENCER FACTORY — Guía rápida v1.0

## 1. Qué es

AI Influencer Factory es un sistema asistido por IA para diseñar, documentar, producir y mantener influencers virtuales consistentes. La arquitectura principal utiliza **Sistema 00 + F01–F13**.

## 2. Cómo empezar

Para un proyecto nuevo escribe:

```text
Crear influencer
```

o:

```text
Crear proyecto
```

La factoría recuperará lo que ya sepa y pedirá solo la información crítica que falte. Los cinco fundamentos mínimos son:

1. fuente de ingreso inicial;
2. nicho;
3. audiencia;
4. tiempo disponible;
5. objetivo a 90 días.

## 3. Cómo continuar

Comandos cotidianos útiles:

```text
Continuar.
¿Dónde quedamos?
Muéstrame el estado.
¿Qué falta?
Aprueba esta fase.
Simula este cambio sin aplicarlo.
Valida todo.
Dame el canon actual.
Crea el siguiente entregable.
Prepara el contexto para otra IA.
```

## 4. Qué significa aprobar

```text
PROPUESTA / SIMULACIÓN / RECOMENDACIÓN
≠
CANON
```

Una decisión canónica solo se bloquea después de aprobación explícita suficiente. Cambiarla después exige revisión controlada e impacto sobre dependencias.

## 6. Canon, operación y derivados

```text
CANONICAL
= verdad aprobada/bloqueada de una fase propietaria

DYNAMIC
= estado operativo que puede cambiar con trazabilidad

DERIVED
= artefacto regenerable desde canon/estado

HISTORICAL
= versión o decisión anterior preservada

PENDING
= dato, validación o acción todavía no resuelta
```

No todo lo que aparece en el Perfil Maestro es canon.

## 7. Si no sabes qué responder

Puedes decir:

```text
No sé.
Dame opciones.
Recomiéndame.
Decide tú.
Haz lo mejor.
```

La IA puede ayudarte a descubrir y comparar opciones, pero no debe saltarse aprobaciones obligatorias ni modificar canones bloqueados sin una revisión autorizada.

## 8. Migrar a otra IA

Solicita:

```text
Prepara el contexto para otra IA.
```

La factoría seleccionará uno de estos formatos:

- Paquete Portable Completo;
- Paquete Portable Ligero;
- Archivo Universal de Reanudación;
- Contexto Portable Copiable.

Después:

1. abre una conversación nueva en la IA destino;
2. adjunta el paquete o pega el contexto;
3. escribe `Continuar [Nombre Influencer]`.

La IA destino no debe reconstruir el proyecto ni repetir preguntas ya resueltas.

## 9. Si la IA no genera imágenes, video o voz

El proyecto puede continuar en Modo Básico Universal. AIIF prepara prompts, paquetes y referencias; el activo se produce externamente y vuelve al sistema para validación.

## 10. Documentación

La documentación oficial se organiza en:

```text
01-manuales
02-guias
03-documentacion-uso
04-plantillas
05-especificaciones-tecnicas
```

La documentación debe estar **siempre accesible, pero no siempre visible**.

## 11. Regla de seguridad operativa

No borres decisiones históricas, no conviertas un resultado bonito en canon automáticamente y no uses un documento derivado como sustituto de Sistema 00 o de la fase propietaria.
