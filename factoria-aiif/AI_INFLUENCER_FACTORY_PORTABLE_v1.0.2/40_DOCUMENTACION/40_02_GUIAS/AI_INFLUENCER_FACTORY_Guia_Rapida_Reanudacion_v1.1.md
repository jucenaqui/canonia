# AI Influencer Factory — Guía Rápida de Reanudación v1.1

## Uso normal

1. Abre una IA compatible.
2. Adjunta el paquete portable de tu influencer.
3. Escribe únicamente:

`Continuar [Nombre Influencer]`

Ejemplo:

`Continuar Mi Influencer`

La IA debe recuperar automáticamente el proyecto, el canon, el estado, los pendientes, las referencias faltantes y la siguiente acción.

## Si el ZIP completo no funciona bien

Adjunta el `UNIVERSAL_RESUME.md` del proyecto y vuelve a escribir exactamente el mismo comando:

`Continuar [Nombre Influencer]`

No debes explicar manualmente el historial del proyecto.

## Solo para diagnóstico técnico

Usa prompts largos de recuperación únicamente cuando estés probando compatibilidad o depurando una migración.
